ALU operation
The ALU is an 8-bit synchronous Arithmetic Logic Unit that performs arithmetic and logical operations on two 8-bit operands. The operation is selected using a 3-bit control signal. The output result is registered on the rising edge of the clock.
The ALU performs computation using fundamental digital logic elements such as adders, subtractors, XOR gates, AND/OR gates, and unsigned comparators. No internal storage elements or feedback paths are used, making the ALU a purely combinational circuit. This design choice ensures low latency and predictable timing behavior.

ALU Functional Principle

Reset Behavior:
- When rst = 1 (HIGH): The output Y is reset to 8'h00 on the rising clock edge
- When rst = 0 (LOW): Normal ALU operations are performed based on the op signal

Let A and B be the two 8-bit input operands, and op be the 3-bit operation selector. The ALU evaluates the selected operation based on op and rising edge of clock and produces the corresponding output Y.

Each operation is computed independently, and a multiplexer selects the final output according to the operation code. Arithmetic operations are performed using 8-bit unsigned arithmetic, while logical operations are applied bitwise across the operands.

The ALU supports the following operations:

Addition (ADD)
Computes the sum of operands A and B.

Subtraction (SUB)
Computes the difference of operands A and B.

Bitwise AND
Performs logical AND on corresponding bits of A and B.

Bitwise OR
Performs logical OR on corresponding bits of A and B.

Bitwise XOR
Performs logical XOR on corresponding bits of A and B.

Set-on-Less-Than (SLT)
Compares operands A and B and sets the output to 1 if A is less than B; otherwise, sets the output to 0.
