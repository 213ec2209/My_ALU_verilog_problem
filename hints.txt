1. Reset Behavior: When rst = 1 (HIGH), the output Y should be reset to 8'h00 on the rising clock edge. When rst = 0 (LOW), normal ALU operations are performed. The reset is synchronous.
2. ALU operations: The number of arithmetic operations depends upon the op value which determines what operation is performed.
3. The ALU computation logic is purely combinational, but the output Y is registered on the clock edge.
4. Pay close attention to when the testbench samples the ALU output - it will be one clock cycle after the inputs are applied.
